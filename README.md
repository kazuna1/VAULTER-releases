# VAULTER: downloads

Local-only, TPM-bound credential vault for Windows.

## Download

**[⬇ Download the latest installer](https://github.com/kazuna1/VAULTER-releases/releases/latest)**: open the
latest release and click `VAULTER_<version>_x64_en-US.msi`.

Already installed? Open VAULTER → Settings → **Check for updates**.

Windows may show "Windows protected your PC / Unknown publisher" on first install
(the installer isn't Authenticode-signed). Click *More info → Run anyway*.
Updates installed from inside the app are verified with VAULTER's update-signing key.

This repository only hosts release files.
